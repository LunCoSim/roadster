# Tesla Roadster Runner

A Tesla Roadster model and driving course made for LunCoSim.

## Run it in LunCoSim

1. **Download and install LunCoSim** from the [official download page](https://lunco.space/download). Choose the installer for your operating system.
2. **Get this project.** Clone it with Git:

   ```sh
   git clone https://github.com/LunCoSim/roadster.git
   ```

   Or use **Code → Download ZIP** on the [project page](https://github.com/LunCoSim/roadster), then extract the archive.
3. **Open the Twin.** Start LunCoSim and choose **Open Twin**. Select the project folder that contains `twin.toml` (the repository root, or the extracted `roadster-main` folder). Select the folder, not a `.usda` scene file.
4. **Drive.** LunCoSim loads **Roadster Cinematic** by default. Choose **Run Autopilot** to watch a run, or focus the simulator window and use **W/S** to accelerate or reverse, **A/D** to steer, **Space** for boost, and **Shift** to brake. Press **K** for the lift jets and **F** to toggle the fans.

## About the model

This Twin includes the car, a driving course, and the models that make it drive.
